Local AI Setup & Troubleshooting Guide

AccessAble AI runs 100% locally on your computer using Ollama. No API keys, no subscriptions, and complete data privacy. Follow the instructions below to verify or configure models.

Windows PowerShell Commands

Run these commands in Windows PowerShell (or Command Prompt) to set up or verify Ollama:

Step 1

Verify Ollama Installation

ollama --version

If not installed, run: winget install Ollama.Ollama

Step 2

Download Recommended Text Model (llama3.2)

ollama pull llama3.2

For low-RAM machines (4 GB RAM), use: ollama pull llama3.2:1b

Step 3

Download Vision Model for Image Descriptions (Optional)

ollama pull moondream

Compact vision model: moondream (1.7 GB). Larger model ollama pull llama3.2-vision is also supported.

Step 4

Test Model Locally in Terminal

ollama run llama3.2:1b "Explain accessibility in one short sentence"
